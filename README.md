# Emotion Bloom Web AR

一个在浏览器中运行的实时表情 AR 原型。目前聚焦自然态、微笑和大笑，并提供可切换的 1.0 像素版与 2.0 液态荧光版。摄像头画面和人脸推理只在当前设备内处理，不录制、不上传。

## 当前体验

- 摄像头启动后仅在底部安全区显示一条动态引导，加载、校准和表情反馈不会上下重复出现
- 实时状态卡默认隐藏，仅在用户主动展开调试面板时显示
- 用户点击后才请求摄像头权限，移动端优先前置摄像头并镜像显示
- MediaPipe Face Landmarker 单脸识别，模型及 WASM 均从本地资源加载
- 自然表情、个人微笑峰值和个人张嘴峰值动态校准
- Smile 融合嘴角上扬、脸颊抬起与酒窝信号，不依赖单一嘴唇阈值
- 大笑综合标准化笑容与张嘴幅度，支持三条判定通路并过滤普通说话
- 表情信号采用质量过滤、EMA 平滑、进入/退出滞回和持续时间确认
- 大笑高潮需稳定保持约 660ms；同一轮大笑只触发一次，冷却 1.5 秒
- 大笑结束后若仍保持微笑，会先回落到微笑态，再自然回到待机态

## 视觉版本

顶部 `1.0 / 2.0` 开关可实时切换，默认启用 2.0。1.0 的像素雨和像素烟花实现完整保留。

### 2.0 液态荧光

- 微笑：半透明乳白、冰蓝和蓝紫果冻雨滴从顶部凝结，密度随表情能量平滑增加
- 雨滴：缓慢漂移、拉伸和旋转，碰到头部后挤压、沿轮廓滑动并带阻尼弹开
- 落地：底部绿色舞台光承接雨滴，依次产生液态涟漪和半透明四叶花
- 大笑：绿色舞台光增强，蓝、紫、品红与亮黄渐变光球从底部上升、压缩，再柔软绽放
- 雕塑烟花：大型透明圆环、软刺星芒、四叶液态花与云状果冻团块分批扩散，保留中央黑色负空间
- 材质：乳白高光、彩色体积阴影、荧光轮廓与预生成半调网点共同形成充气酸性玻璃质感
- 收尾：形体逐渐失去内部亮度并纵向融化，持续大笑不会重复爆发
- 人脸保护：元素经过眼睛和嘴部区域自动降低亮度，并继续使用实时头部碰撞体

### 1.0 像素版

- 自然态：极弱蓝紫轮廓光、三颗绕头光粒子和 4 秒循环的透明极光
- 微笑 0–900ms：Cyan、粉、紫、薄荷绿和橙色小色块沿纵向轨道由稀到密出现
- 持续微笑：像素短线与方块以不同速度、大小和景深下落，经过面部区域时自动压低亮度
- 大笑候选：雨滴先减速并淡出，不再在用户脸周生成大型圆环
- 微笑结束：现有雨滴继续下落并平滑熄灭，不突然清屏
- 大笑：由画面顶部直接绽放霓虹像素烟花；大型笑脸构成视觉重心，乐符、星星、花朵与分段射线按大小层级错时爆发
- 像素烟花仍使用有限对象池与实时头部椭圆碰撞体，可被头部移动撞散

## 工程与性能

- 摄像头、推理、表达分析、状态机、故事导演、视觉系统和性能控制分离
- 人脸推理约 15 FPS，PixiJS 渲染独立使用 `requestAnimationFrame`
- 微笑效果使用 112 个预创建 Sprite 对象池，并按画质启用 48／76／104 个元素
- 大笑粒子使用固定对象池，桌面端上限 320、移动端上限 220
- 2.0 微笑使用 42 个果冻雨滴与 10 组落地反馈对象池，大笑使用 32 个液态雕塑对象池
- DPR 限制为 1.25–1.5，并根据实时 FPS 自动切换画质等级
- 页面进入后台时暂停 PixiJS Ticker；退出体验时释放摄像头和渲染资源
- 调试面板显示表情分数、状态候选进度、FPS、粒子量和碰撞耗时

## 本地运行

```bash
npm install
npm run dev
```

无需开启摄像头即可按 `S` 模拟微笑、按 `L` 模拟大笑、按 `N` 回落到自然态，按 `Esc` 恢复实时输入。

## 验证

```bash
npm exec -- tsc --noEmit
npm run build
```
