# Emotion Bloom Web AR

一个在浏览器中运行的实时表情 AR 原型。目前聚焦自然态、微笑和大笑：微笑会从嘴角向脸颊生长出全息花瓣，大笑会沿用微笑元素升级成一次性的“快乐超载”。摄像头画面和人脸推理只在当前设备内处理，不录制、不上传。

## 当前体验

- 用户点击后才请求摄像头权限，移动端优先前置摄像头并镜像显示
- MediaPipe Face Landmarker 单脸识别，模型及 WASM 均从本地资源加载
- 自然表情、个人微笑峰值和个人张嘴峰值动态校准
- Smile 融合嘴角上扬、脸颊抬起与酒窝信号，不依赖单一嘴唇阈值
- 大笑综合标准化笑容与张嘴幅度，支持三条判定通路并过滤普通说话
- 表情信号采用质量过滤、EMA 平滑、进入/退出滞回和持续时间确认
- 大笑高潮需稳定保持约 660ms；同一轮大笑只触发一次，冷却 1.5 秒
- 大笑结束后若仍保持微笑，会先回落到微笑态，再自然回到待机态

## Emotion Bloom 视觉系统

- 自然态：极弱蓝紫轮廓光、三颗绕头光粒子和 4 秒循环的透明极光
- 微笑 0–150ms：两侧嘴角点亮 Cyan/Hot Pink 星芒
- 微笑 150–400ms：两条透明光丝沿脸颊向上生长
- 微笑 400–800ms：眼角外侧出现少量全息玻璃花瓣
- 微笑 800–1200ms：头后形成一段不完整的青粉紫柔光弧
- 持续微笑：脸部元素只做呼吸，不重复爆发，也不再生成满屏花瓣雨
- 微笑结束：固定数量花瓣沿脸部外轮廓短暂消散
- 大笑：微笑花瓣先外张，再升级为霓虹像素烟花；方块矩阵、分段射线、字符符号与像素环错时爆发
- 像素烟花仍使用有限对象池与实时头部椭圆碰撞体，可被头部移动撞散

## 工程与性能

- 摄像头、推理、表达分析、状态机、故事导演、视觉系统和性能控制分离
- 人脸推理约 15 FPS，PixiJS 渲染独立使用 `requestAnimationFrame`
- 微笑效果仅使用 36 个预创建 Sprite，不在每帧创建对象
- 大笑粒子使用固定对象池，桌面端上限 320、移动端上限 220
- DPR 限制为 1.25–1.5，并根据实时 FPS 自动切换画质等级
- 页面进入后台时暂停 PixiJS Ticker；退出体验时释放摄像头和渲染资源
- 调试面板显示表情分数、状态候选进度、FPS、粒子量和碰撞耗时

## 本地运行

```bash
npm install
npm run dev
```

无需开启摄像头即可按 `S` 模拟微笑、按 `L` 模拟大笑、按 `N` 回落到自然态，按 `Esc` 恢复实时输入。

## 验证

```bash
npm exec -- tsc --noEmit
npm run build
```
