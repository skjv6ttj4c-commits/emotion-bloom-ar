# Pixel Live Web AR

一个在浏览器中运行的实时表情 AR 原型。页面、交互引导和特效统一采用黑白、亮黄、钴蓝与少量粉色组成的高级像素视觉。摄像头画面和人脸推理只在当前设备内处理，不录制、不上传。

## 当前体验

- 首屏以英文 `WELCOME BACK TO THE LIVE ROOM.` 引导用户主动开启摄像头
- 摄像头启动后，左下角以 3 张放大的像素角色图提供微笑、大笑和双手比心引导
- 三种表情或动作均已接入对应识别与特效，不再包含敬礼和捂嘴惊讶入口
- 实时状态卡默认隐藏，仅在用户主动展开调试面板时显示
- 用户点击后才请求摄像头权限，移动端优先前置摄像头并镜像显示
- MediaPipe Face Landmarker 单脸识别，模型及 WASM 均从本地资源加载
- 页面可交互后并行预取人脸模型和当前设备匹配的 SIMD／非 SIMD WASM；用户可直接开启摄像头，识别引擎在直播画面后方继续准备
- 模型下载展示真实字节进度，下载、视觉引擎准备和识别初始化使用独立状态，不再停留在固定的 18%
- 打开摄像头后仅在后台快速记录自然基线，不再要求用户预先微笑或张嘴；个人峰值在互动过程中静默自适应
- Smile 融合嘴角上扬、脸颊抬起与酒窝信号，不依赖单一嘴唇阈值
- 大笑综合标准化笑容与张嘴幅度，支持三条判定通路并过滤普通说话
- 表情信号采用质量过滤、EMA 平滑、进入/退出滞回和持续时间确认
- 大笑高潮需稳定保持约 660ms；同一轮大笑只触发一次，冷却 1.5 秒
- 大笑结束后若仍保持微笑，会先回落到微笑态，再自然回到待机态

## 像素视觉与动效

- 自然态：极弱蓝紫轮廓光、三颗绕头光粒子和 4 秒循环的透明极光
- 微笑 0–900ms：Cyan、粉、紫、薄荷绿和橙色小色块沿纵向轨道由稀到密出现
- 持续微笑：像素短线与方块以不同速度、大小和景深下落，经过面部区域时自动压低亮度
- 大笑候选：雨滴先减速并淡出，不再在用户脸周生成大型圆环
- 微笑结束：现有雨滴继续下落并平滑熄灭，不突然清屏
- 大笑：由画面顶部直接绽放霓虹像素烟花；大型笑脸构成视觉重心，乐符、星星、花朵与分段射线按大小层级错时爆发
- 像素烟花仍使用有限对象池与实时头部椭圆碰撞体，可被头部移动撞散
- 双手比心：两手拇指与食指关系稳定确认后，在手部位置长出人脸尺度的主爱心，清脆分裂为沿脸部和上半身轮廓流动的小爱心；底部心跳光晕从首帧开始，5.35 秒同步淡出

## 工程与性能

- 摄像头、推理、表达分析、状态机、故事导演、视觉系统和性能控制分离
- 人脸推理约 15 FPS、手部推理约 10 FPS，PixiJS 渲染独立使用 `requestAnimationFrame`
- 微笑效果使用 112 个预创建 Sprite 对象池，并按画质启用 48／76／104 个元素
- 大笑粒子使用固定对象池，桌面端上限 320、移动端上限 220
- DPR 限制为 1.25–1.5，并根据实时 FPS 自动切换画质等级
- 页面进入后台时暂停 PixiJS Ticker；退出体验时释放摄像头和渲染资源
- 手部模型与 WASM 使用本地资源，不依赖运行时第三方 CDN
- 人脸模型与实际使用的 WASM 通过版本化 Cache Storage 和 Service Worker 跨会话复用；12 秒无数据时自动重试一次
- 首选同源模型资源；若首包或下载连续 12 秒无响应，则自动切换到不可变版本的 CDN 备份，避免弱网无限卡住
- PixiJS 视觉引擎延后到人脸运行时就绪后初始化，首进阶段不再与核心识别资源争抢移动网络带宽
- 调试面板显示表情/手势分数、候选进度、推理耗时、FPS、粒子量和碰撞耗时

## 本地运行

```bash
npm install
npm run dev
```

无需开启摄像头即可按 `S` 模拟微笑、按 `L` 模拟大笑、按 `H` 预览比心、按 `N` 回落到自然态，按 `Esc` 恢复实时输入。

## 验证

```bash
npm exec -- tsc --noEmit
npm run build
```
